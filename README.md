# Attendance Tracker using Python

## Project Overview
A Python-based attendance tracking system that calculates student attendance percentage and checks eligibility based on attendance records. The project uses Python, Pandas, and Excel file handling to process student data.

## Features
- Calculate attendance percentage
- Read student data from Excel files
- Search and manage attendance records
- Apply attendance eligibility conditions

## Technologies Used
- Python
- Pandas
- Excel File Handling
- Object-Oriented Programming
